# iMile Townsville 运营管理 - 业务说明

## 一、业务模型

### 1. 人员管理
- **司机团队**：全职 + 兼职
- **账号体系**：每个司机有固定账号，特殊情况使用备用账号
- 需要记录：司机姓名、类型（全职/兼职）、主账号、备用账号、联系方式等

### 2. 每日运营
- iMile 每天提供分区好的派送任务
- Ray 将任务分配给司机执行
- 司机使用各自账号登录完成派送

### 3. 数据核对（每周一）
- 从 iMile 系统导出/查询每个账号的派送数据
- 将同一司机的多个账号数据汇总
- 确认派送量、成功率、异常件等

### 4. 工资计算
- **周期**：按周计算
- **发放**：延迟两周
- **计算基础**：派送数据 × 单价
- **扣项**：罚款（从司机工资中扣回）
- **资金来源**：总部提供现金

### 5. 资金管理
- 总部拨款（工资 + 运营费用）
- 司机工资发放
- 运营费用支出
- 罚款收支（总部罚款 → 向司机追回）

## 二、关键数据实体

| 实体 | 说明 |
|------|------|
| 司机 | 姓名、类型、主账号、备用账号、状态 |
| 账号 | 账号ID、绑定司机、类型（主/备） |
| 派送数据 | 账号、日期、派送量、成功/失败/异常 |
| 工资单 | 周期、司机、基础工资、扣款、实发 |
| 资金流水 | 日期、类型（拨款/发放/费用/罚款）、金额、备注 |
